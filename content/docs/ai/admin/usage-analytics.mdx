Usage Analytics shows AI activity volume and provider telemetry.

<Callout type="info">
Usage Analytics is designed for operational visibility: adoption, provider load, token volume, and error trends.
</Callout>

## Metrics

The panel tracks:

- task counts
- completed, failed, cancelled, and pending status counts
- input tokens
- output tokens
- total tokens

## Breakdowns

Usage can be grouped by:

- organization
- user
- provider
- model
- status
- date bucket

## Operational telemetry

Usage analytics help administrators understand AI activity, provider usage, and error patterns across organizations and users.

## Common uses

- find organizations with heavy AI usage
- compare provider/model usage
- inspect failure rates
- estimate provider load during pilots

## Example questions

| Admin question | Where to look |
| :--- | :--- |
| Which organization is using AI most? | Organization breakdown |
| Which provider has the most failures? | Provider/model status table |
| Did a model change increase token usage? | Date range plus model grouping |
| Which users are testing action previews? | User breakdown and task status counts |
